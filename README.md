# bot-bom issues

**bot-bom** is a web app for numbering parts and managing bills of materials (BOMs), built for robotics teams and their mentors. It is live at <https://bot-bom.quantumwhatever.com>.

This repository is the **public issue list** for bot-bom. Use it to report bugs, ask for features, or ask questions. The app's source code is private and is not in this repo.

## Filing an issue

You need a free [GitHub account](https://github.com/signup) to file an issue. Then open [a new issue](../../issues/new/choose) and pick a template.

A good issue includes:

- **The version.** In the app, open **About → This build** and paste what it shows.
- **Steps to reproduce.** What you clicked or entered, in order.
- **What you expected, and what happened instead.**
- **Screenshots** where they help. Drag them into the issue box.

Please check the [open issues](../../issues) first; someone may have reported it already, and you can add to that one.

Please don't post passwords or other private information in an issue. Everything here is public.
